# Roadmap

## 0.2 — power operations

- Batch rename with tokens, counters, regex capture groups, preview, and undo log.
- Folder compare and one/two-way synchronization with dry-run and conflict review.
- A visible operation queue with pause, cancel, retry, and per-byte progress.
- Folder favorites and persisted window/tab sessions.
- Automatic directory refresh using filesystem events.

## 0.3 — provider layer

- Browse ZIP/TAR archives as read-only folders, then safe extraction and archive creation.
- SFTP provider using system SSH configuration and Keychain-backed credentials.
- Provider capability model so unsupported operations are disabled before execution.

## 0.4 — analysis tools

- Disk usage treemap/list with cancellable scanning.
- Checksums and duplicate candidate search.
- Saved searches and reusable search presets.
